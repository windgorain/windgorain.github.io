操作系统安装指南

Windows

到下载页面下载Windows客户端到本地，然后进行解压，进入解压后的目录运行vnmesh程序

如果您希望开机自动启动，则需要执行vnmesh_root，然后可以到管理页面的"系统设置-系统配置"中管理自启动设置

MacOS

到下载页面下载对应平台的MacOS客户端，然后如下操作:

tar xzf vnmesh_macos_apple_1.2.1.tar.gz  #绿色部分改为您下载文件的名字
cd vnmesh
xattr -rd com.apple.quarantine vnmesh #这条命令仅需执行一次, 后续不用再执行
./vnmesh -d

#可以通过telnet查看配置
telnet localhost 2300

然后可以到管理页面的"系统设置-系统配置"中管理自启动设置

Linux

到下载页面下载对应平台的Linux客户端，然后解压和运行:

tar xzf vnmesh_linux_x64_1.2.1.tar.gz  #绿色部分改为您下载文件的名字
cd vnmesh
./vnmesh -d

#可以通过telnet查看配置
telnet localhost 2300

然后可以到管理页面的"系统设置-系统配置"中管理自启动设置

Docker

到下载页面下载Docker镜像

docker load -i vnmesh_docker_x64_1.2.1.tar #绿色部分改为您下载文件的名字 
docker run -p 8888:8888 -d --name vnmesh vnmesh

#可以通过telnet查看配置
docker exec -ti vnmesh telnet localhost 2300

然后可以到管理页面的"系统设置-系统配置"中管理自启动设置

路由器

到下载页面下载路由器版本，通常是MIPSEL版本(较新的路由器)或MIPS版本(老旧路由器), 然后如下操作

 #将软件上传到路由器
scp -O vnmesh_linux_mipsel_1.2.1.tar.gz root@192.168.1.1:~/ 

#登录路由器
ssh root@192.168.1.1
root@192.168.1.76's password:  #输入路由器管理员密码

#解压文件
tar xzf vnmesh_linux_mipsel_1.2.1.tar.gz
rm -fr vnmesh_linux_mipsel_1.2.1.tar.gz

#运行vnmesh
cd vnmesh
./vnmesh -d

为了使路由器重启后，自动启动VNMesh，可以编辑/etc/rc.local文件，添加如下绿色一行: 

# Put your custom commands here that should be executed once
# the system init finished. By default this file does nothing.

/root/vnmesh/vnmesh -d 

exit 0

然后就可以通过浏览器访问VNMesh管理系统: 

 http://192.168.1.2.1888
