show instance

显示实例信息

命令格式: sudo ./mgwtool show instance

示例: 

$ sudo ./mgwtool show instance
 instance:acl, mgw:ip_acl, class:leaf, in:xdp, out:none, enable:1
 instance:xdpevent, mgw:xdp_event, class:leaf, in:xdp, out:none, enable:1
 instance:ttriode, mgw:ttriode, class:traffic, in:xdp, out:xdp, enable:1

显示说明

instance实例名
mgwMGW名
classMGW类别: traffic/cluster/pipe/leaf
in入口类型
out出口类型
enable是否使能. 0: 停止工作; 1: 正在工作
