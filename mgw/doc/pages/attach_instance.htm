attach instance

将实例关联到上游实例

命令格式: sudo ./mgwtool attach instance -n 实例名 -t 目标实例 [-p 入口函数名] [-s 指定插槽号] [-w 权重]

示例: 

$ sudo ./mgwtool load instance -n c1 -f cluster/xdp_ip_cluster_kern.o
$ sudo ./mgwtool load instance -n p1 -f leaf/xdp_ip_printer_leaf_kern.o
$ sudo ./mgwtool load instance -n p2 -f leaf/xdp_ip_printer_leaf_kern.o
$ sudo ./mgwtool tree instance
c1
p1
p2

$ sudo ./mgwtool attach instance -n p1 -t c1
$ sudo ./mgwtool attach instance -n p2 -t c1
$ sudo ./mgwtool tree instance
c1
├── p1
└── p2

上述示例加载了三个MGW实例: c1/p1/p2。在未关联时, 三个实例之间无上下游关系。关联之后, c1连接到了下游两个实例:p1和p2

说明

-pMGW的入口函数名, 默认为mgw_input
-s关联的插槽号, 如果未指定则自动分配
-w当关联到cluster类实例上时, 可以指定流量分配权重. 范围1-255, 数字越大权重越高
