url_filter_leaf

中文名

URL过滤器

作用

对报文/内层报文携带的HTTP/SSL头中的域名做过滤

需求

需要KLC环境支持

MGW文件

leaf/xdp_url_filter_leaf_klc.o

leaf/xdp_vxlan_inner_url_filter_leaf_klc.o

leaf/xdp_geneve_inner_url_filter_leaf_klc.o

leaf/tc_url_filter_leaf_klc.o

leaf/tc_vxlan_inner_url_filter_leaf_klc.o

leaf/tc_geneve_inner_url_filter_leaf_klc.o

控制程序

leaf/mgw-urlfilter

注意

白名单优先级高于黑名单, 如果一个域名在黑白名单中都存在, 则会优先匹配到白名单。

示例脚本


#/bin/bash
#文件名称: xdp_url_filter.sh
#使用方法: ./xdp_url_filter.sh 接口
#使用示例: ./xdp_url_filter.sh eth0
#终止脚本: Ctrl+C

IF_NAME=eth0
if [ "$1" ];then
    IF_NAME=$1
fi

#加载 url filter
./mgwtool load instance -n u1 -f leaf/xdp_url_filter_leaf_klc.o
#关联到接口
./mgwtool attach xdp -n u1 -t ${IF_NAME} -p mgw_input

#添加黑白名单, 允许www.baidu.com的报文, 禁止*.baidu.com的报文
./leaf/mgw-urlfilter add -n u1 -l whitelist -H www.baidu.com
./leaf/mgw-urlfilter add -n u1 -l blacklist -H *.baidu.com

./mgwtool enable all

trap finish INT
finish () {
    echo ""
    echo "quit..."
    #从接口解除关联
    ./mgwtool deta xdp -t ${IF_NAME}
    #卸载所有instance
    ./mgwtool unload all-instance
    exit
}

sleep infinity
