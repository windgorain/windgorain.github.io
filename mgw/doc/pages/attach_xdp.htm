attach xdp

将实例关联到接口的XDP入口

命令格式: sudo ./mgwtool attach xdp -n 实例名 -t 接口名 [-p 入口函数名] [-m 加载模式]

示例: 

$ sudo ./mgwtool attach xdp -n c1 -t eth0
$ sudo ./mgwtool tree instance
[eth0]
└── c1

说明

-pMGW的入口函数名, 默认为mgw_input
-m加载模式:
2: skb模式, 通用模式, 一般性能水平
4: driver模式, 较高性能, 少量网卡驱动不支持
8: hw模式, 最高性能模式, 部分网卡支持
