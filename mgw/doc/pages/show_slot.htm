show slot

显示实例插槽

命令格式: sudo ./mgwtool show slot [-n 实例名]

示例: 

$ sudo ./mgwtool show slot
instance:ttriode, slot:0, sub-instance:xdpevent
instance:ttriode, slot:1, sub-instance:acl

$ sudo ./mgwtool show slot -n ttriode
instance:ttriode, slot:0, sub-instance:xdpevent
instance:ttriode, slot:1, sub-instance:acl

显示说明

instance实例名
slot实例插槽号
sub-instance关联到此插槽的下游实例
