show statics

显示实例统计信息

命令格式: sudo ./mgwtool show statics [-n 实例名]

示例: 

$ sudo ./mgwtool show statics
 instance:acl, pkt-in:335667, pkt-drop:6534
 instance:xdpevent, pkt-in:337785, pkt-drop:0
 instance:ttriode, pkt-in:337785, pkt-drop:6534

$ sudo ./mgwtool show statics -n acl
 instance:acl, pkt-in:335778, pkt-drop:6537

显示说明

instance实例名
pkt-in进入实例的报文个数
pkt-drop本实例丢弃报文个数
