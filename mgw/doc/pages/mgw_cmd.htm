命令说明

mgwtool version显示mgwtool版本号
mgwtool tree instance显示实例之间的关联关系
mgwtool show instance显示当前加载的实例
mgwtool show statics显示实例的统计信息
mgwtool show attr显示实例属性
mgwtool show slot显示实例的插槽信息
mgwtool show vslot显示实例的虚拟插槽信息
mgwtool load instance从指定文件加载一个实例
mgwtool unload instance卸载一个实例
mgwtool unload all-instance 卸载所有实例
mgwtool attach xdp 将实例关联到接口的XDP入口
mgwtool detach xdp 从接口解关联XDP
mgwtool attach tc 将实例关联到接口的TC入口
mgwtool attach instance 将实例关联到上游实例
mgwtool detach instance 将实例从上游实例解除关联
mgwtool detach all-instance 解关联指定实例的所有下游实例
mgwtool enable instance使指定实例开始工作
mgwtool disable instance使指定实例停止工作
mgwtool enable all开始所有实例的工作
mgwtool disable all停止所有实例的工作
