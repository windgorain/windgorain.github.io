attach tc

将实例关联到接口的TC入口

命令格式: sudo ./mgwtool attach tc -n 实例名 -t 接口名 [-p 入口函数名] [-a 加载位置]

示例: 

$ sudo ./mgwtool load instance -n t1 -f cluster/tc_ip_cluster_kern.o
$ sudo ./mgwtool attach tc -n t1 -t eth0
$ sudo ./mgwtool tree ins
[eth0]
└── t1

$ sudo tc filter del dev eth0 ingress #解除关联

说明

-pMGW的入口函数名, 默认为mgw_input
-m加载位置:
1: ingress (缺省加载位置)
2: egress
4: custom
