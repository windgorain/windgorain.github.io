load instance

加载实例

命令格式: sudo ./mgwtool load instance -f 文件名 -n 实例名 [-d 描述信息] [-l 标签]

示例: 

$ sudo ./mgwtool load instance -n c1 -f cluster/xdp_ip_cluster_kern.o -d 描述示例 -l 标签示例
$ sudo ./mgwtool show attr -n c1
mgw: ip_cluster
instance: c1
description: 描述示例
label: 标签示例
class: cluster
in_type: xdp
out_type: xdp
enable: 0

说明

-f指定MGW文件
-n加载的实例名称
-d描述信息
-l标签信息
