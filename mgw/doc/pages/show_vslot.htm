show vslot

显示实例虚拟插槽, 本命令用于cluster类实例

命令格式: sudo ./mgwtool show vslot [-n 实例名]

示例: 

$ sudo ./mgwtool tree instance
[eth0]
└── c1
    ├── p1
    ├── p2
    ├── p3
    └── p4

$ sudo ./mgwtool show instance
 instance:c1, mgw:ip_cluster, class:cluster, in:xdp, out:xdp, enable:1
 instance:p4, mgw:ip_printer, class:leaf, in:xdp, out:none, enable:1
 instance:p3, mgw:ip_printer, class:leaf, in:xdp, out:none, enable:1
 instance:p2, mgw:ip_printer, class:leaf, in:xdp, out:none, enable:1
 instance:p1, mgw:ip_printer, class:leaf, in:xdp, out:none, enable:1

$ sudo ./mgwtool show vslot -n c1
instance:c1, vslot:0, slot:1
instance:c1, vslot:1, slot:3
instance:c1, vslot:2, slot:0
instance:c1, vslot:3, slot:3
instance:c1, vslot:4, slot:0
instance:c1, vslot:5, slot:1
instance:c1, vslot:6, slot:0
instance:c1, vslot:7, slot:3
instance:c1, vslot:8, slot:1
instance:c1, vslot:9, slot:0
......
instance:c1, vslot:2044, slot:2
instance:c1, vslot:2045, slot:0
instance:c1, vslot:2046, slot:2
instance:c1, vslot:2047, slot:2

上述示例中, c1实例下关联了4个下游实例:p1/p2/p3/p4, 其对应的插槽号分别为0/1/2/3。
c1实例共有2048个虚拟插槽, 分别关联到了这4个真实插槽, 从而关联到了下游实例。
c1会对报文进行五元组hash, 然后根据hash结果将报文分别传递给下游不同实例。
